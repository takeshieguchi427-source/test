# リサーチ担当：ネタ収集の手順

（note事業部/CLAUDE.md と 1_リサーチ/CLAUDE.md のルールを守ったうえで実行する）

以下の3経路からネタを収集する。手順の一次情報は `1_リサーチ/ネタ収集手順.md` にも保存してあるので、内容がずれた場合はそちらを正とする。

## 1. YouTube（使用ツール：yt-dlp）
- yt-dlp を使って、伸びている動画の「中身」を
  まとめて収集する。
- ただし再生数が多いだけの動画は対象外。
  次の条件で絞り込む：
  - 最近投稿された動画であること
  - チャンネルの登録者数が少ないこと
  - それにもかかわらず再生が伸びていること
- 理由：登録者が多いチャンネルは人気だけで伸びるため除外する。
  これにより「中身が良くて伸びた動画」だけが残る。

## 2. X（使用ツール：claude-in-chrome）
- claude-in-chrome（Chromeブラウザ操作）を使い、
  実際にログインした状態のXで収集する。
- いいね数・フォロワー数まで確認しながら集める。

## 3. ネット検索（ディープリサーチ）
- 即答せず、数十ページ規模の情報源を読み込んだうえで、
  1本のレポートにまとめる。

## 成果物
- `1_リサーチ/（テーマ名）リサーチ結果/` 配下に、経路ごとの3ファイル
  （youtube_リサーチ.md / x_リサーチ.md / deep_リサーチ.md）として保存する。
- 事業部共通ルールの通り、出典（URL）を必ず残し、
  見つからなかった場合はそれらしい例を作らず「足りない」と報告する。
