### 重要な注記(数値の解釈について)

⑥は9本中ほぼ全てのチャンネルに共通していました。つまり①②の「登録者数を超える再生数」は、動画単体が自然にバズった結果だけでなく、**LINE広告や外部の勉強会・特典配布による流入が寄与している可能性**があります。「オーガニックにバズった」と断定はできない点にご留意ください。特に今回最上位のかいちのAI大学は法人コンサル会社監修のチャンネルであり、この傾向が最も強いと考えられます。

### 抽象化した"伸びる理由"の仮説

1. **「教える」動画より「変化を見せる」動画が伸びやすい、が唯一の型ではない。** 従来、登録者数を超えた②さきのAIでええやん・および同率3位のここなのAI大学は、いずれも「知らなかった自分→できた自分」という一人称のストーリーを前面に出しており、体系的な手順解説に振り切ったキノコードは登録者数比で低い伸びにとどまっていた。しかし今回最上位となった①かいちのAI大学は、体験談ではなく端的な「使い方・活用方法を徹底解説」型でありながら②の約1.9倍の比率を記録している。**体験談型は再現しやすい"個人発信者の型"だが、法人チャンネルでは「煽り見出し＋大量の特典によるリード獲得導線」が体験談なしでも同等以上に伸びる、別の"型"として機能しうる。**
2. **擬人化メタファーが理解の速度を上げている。** いけともchの「コンサルタント→シェフ・マネージャー」のような一発で伝わる比喩は、専門用語を使わずにAIの進化を説明できる点で強い。
3. **ペルソナ限定(初心者・ゼロから・1人起業)が「自分ごと化」を促している。** 個人発信者の上位動画にはこの要素がある一方、①かいちのAI大学は「経営者向け」という広めのペルソナ設定でも上位に来ており、ペルソナ限定は必須条件ではなく強化要因と捉えるのが正確。
4. **発信者の個性(方言・口調)が量産型コンテンツとの差別化になっている。** 個人発信者の中では②さきのAIでええやんがこの傾向が最も強い。
