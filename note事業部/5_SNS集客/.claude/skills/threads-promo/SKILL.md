# SNS集客担当：スレッズ宣伝文の作成手順

（note事業部/CLAUDE.md と 5_SNS集客/CLAUDE.md のルールを守ったうえで実行する）

## 材料
- 完成した記事（`2_記事生成/（テーマ名）記事.md`）とタイトルを読み込み、中身の数字やボリュームを本文から拾って使う。
- noteのURLと価格が必要。未公開・未定の場合は（URL）（価格）のプレースホルダーで作成し、公開後に差し替えるようユーザーに伝える。

## 基本
- メインはスレッズを想定する。
- リンクは本文に貼らず、コメント欄用の文を別で出す。
- 投稿文とコメント欄は必ずセットで出す。
- 1本の投稿で言うことは1つに絞る。

## 文体
- 語尾は「です」で終わらせず、「！」か柔らかい絵文字をつける。
- 中身の数字やボリュームは本文から拾って具体的に入れる。

## 使わない表現
- 「＝」を使った言い切り。
- 「未経験から」。
- 「◯時間→◯分」の時短アピール。
- あおる言い方（「知らないと損」「差がつく」）。

## 成果物
- `5_SNS集客/（テーマ名）スレッズ宣伝.md` に、メイン投稿とコメント欄用リンク文をセットで保存する。
- スレッズ宣伝は繰り返し運用が前提。2本目以降の宣伝投稿もいつでも作れることを伝える。
