# 記事生成担当：記事執筆の手順

（note事業部/CLAUDE.md と 2_記事生成/CLAUDE.md のルールを守ったうえで実行する）

## 材料
- `1_リサーチ/（テーマ名）リサーチ結果/` の3ファイル（youtube_リサーチ.md / x_リサーチ.md / deep_リサーチ.md）を必ず読み込む。
- 材料が足りないときは、想像で埋めずに「足りない」と報告する。

## 進める順番
- いきなり本文を書かない。必ず目次→細かい構成→本文の順。
- 目次・構成をユーザーに見せて、大枠を確認してもらってから本文に入る。
- 本文は1章ずつ書く。まとめて書かない。
- 構成を勝手に省かない。要点は全部カバーする。

## 本文を書き始める前に
- ユーザーに「自分の体験」を1つだけ質問する（記事に説得力を持たせる実体験）。
- 発信者名・ジャンル・読者像は `note事業部/CLAUDE.md` の設定に従う。

## 各章の書き方
- 章のあたまに「この章でわかること」を一言入れる。
- 専門用語は必ず「簡単に言うと〜」で噛み砕く。
- 手順を書くときは、読者がそのとおりに手を動かせる粒度まで降ろす。
- 抽象的な話で終わらせない。必ず具体例を置く。

## 無料部分（購入前に読める範囲）
- 読者のモヤモヤを、こちらから先に言語化する。
- 読んだあとどうなれるのか（未来）を見せる。
- 「この人が言うなら」と思える実体験を入れる。
- 意味のない前置きを書かない（冒頭の一文で離脱される）。

## 使わない表現
- 「寝てる間に」「放置で」などのクリシェ。
- 「すごい」「便利」だけで終わる感想。
- 「これ」「それ」「やつ」などの指示代名詞。直前に出した名前でも、もう一度名前で呼ぶ。

## 成果物
- `2_記事生成/（テーマ名）記事.md` に保存する。
