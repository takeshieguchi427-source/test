# タイトル担当：タイトル案作成の手順

（note事業部/CLAUDE.md と 3_タイトル/CLAUDE.md のルールを守ったうえで実行する）

## 材料
- `2_記事生成/（テーマ名）記事.md` を必ず読み込み、中身と合っているタイトルだけを作る。

## 基本
- タイトル案は10個出す（事業部標準）。各案に推しかどうかと1行の理由を添える。
- 読んだあとに得られるものが分かる形にする。
- 中身と合っていないタイトルは作らない（誇大にしない）。

## 使わない表現
- 誇大・釣り（「絶対」「必ず」「誰でも」「衝撃」）。
- 根拠のない数字や金額。
- 疑問形で逃げる（「〜って知ってますか？」）。
- タイトルだけで意味が分からない、むずかしい言い回し。

## 見出し画像（サムネ）用の文言も添える場合
- 入れる文字は短く。長い文は入れない。
- タイトルと同じことを繰り返さない。

## 成果物
- `3_タイトル/（テーマ名）タイトル案.md` に保存する。
- ユーザーが選んだタイトルは、次工程に進む前に記事ファイルの先頭に反映する。
